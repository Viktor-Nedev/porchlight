## Likely questions (2:00 Q&A)

- **Why not just join a club?** Clubs need commitment and fixed times that clash with commutes. Porchlight is for the next thirty minutes.
- **Is it safe?** Campus-email sign-in, first name only, public spots only, lights expire, block and report and “I have to run” are one tap away.
- **What if the map is empty at first?** Partner clubs keep a few “first lights” on at peak times, and the physical lantern tokens work without the app.
- **Why would people be honest in the forecast?** Only they ever see it.
- **Did you build it?** Yes, there’s a clickable prototype and the code is on GitHub (links on the last slide).
